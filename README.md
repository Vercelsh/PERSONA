# Persona — Личный блокнот подготовки к ЕГЭ

> Разработано компанией **NRT**

Настольное приложение для Windows, созданное на базе **Tauri v2 + React 19 + TypeScript + Tailwind CSS**.

## Особенности
- **Премиальный тёмный дизайн**: минималистичный интерфейс, плавная навигация, кастомный заголовок окна.
- **Поддержка предметов и задач**: формулировки, шаблоны решений, фотографии условий и ответов.
- **Интерактивный календарь дедлайнов**: планирование с метками сложности и статусом выполнения.
- **Оффлайн-хранилище**: мгновенное сохранение в IndexedDB без сторонних серверов.
- **Десктопная интеграция**:
  - Нативная поддержка одного окна (Single Instance) — предотвращает запуск дубликатов.
  - Полноэкранный режим (F11) без артефактов и черных полос.
  - Кастомные кнопки управления окном (свернуть, развернуть на весь экран, закрыть).
  - Защита интерфейса от случайного выделения системного текста.

## Сборка и запуск

### Требования
- [Node.js](https://nodejs.org/) (v18+)
- [Rust](https://rustup.rs/) (версия 1.77+)

### Разработка
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки Tauri
npm run tauri dev
```

### Сборка установщика для Windows (.exe / .msi)
```bash
npm run tauri build
```
Готовый установщик появится в директории `src-tauri/target/release/bundle/nsis/`.

## Автоматическая сборка через GitHub Actions
В репозитории настроен workflow `.github/workflows/build.yml`. При отправке тега или коммита в ветку `main` GitHub Actions автоматически компилирует установщик Windows и выкладывает его в раздел Releases.
