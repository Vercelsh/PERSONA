# Persona

**Локальный блокнот для подготовки к ЕГЭ на Windows.**

Persona помогает организовать самостоятельную подготовку: вести список предметов и заданий, сохранять условия и решения, работать с интерактивной доской и отмечать время занятий в календаре.

- **Предметы и задания** - структурируйте подготовку по своим предметам и задачам.
- **Интерактивная доска** - записывайте решения, добавляйте текст, фигуры и изображения.
- **Календарь занятий** - фиксируйте даты, длительность занятий и количество решённых заданий.
- **Локальное хранение** - данные приложения сохраняются на устройстве в IndexedDB; серверная база данных для учебных записей не используется.

## Скачать Persona

Откройте страницу [Releases](https://github.com/Vercelsh/PERSONA/releases/latest) и скачайте установщик Windows `.exe` из раздела **Assets**.

1. Запустите скачанный установщик.
2. Следуйте инструкциям установщика.
3. Запустите Persona из меню «Пуск» или с ярлыка, если он был создан.

## Хранение данных

Учебные записи, предметы, задания и данные доски хранятся локально на устройстве. Они не синхронизируются между компьютерами автоматически. Удаление приложения, очистка данных WebView2 или сброс профиля пользователя могут повлиять на доступ к локальным данным, поэтому важные записи стоит дополнительно сохранять отдельно.

## Технологии

- [Tauri v2](https://v2.tauri.app/) — оболочка Windows-приложения
- [React 19](https://react.dev/) и [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) — сборка интерфейса
- [Tailwind CSS v4](https://tailwindcss.com/)
- IndexedDB — локальное хранилище учебных данных

## Сборка из исходного кода

### Требования

- Windows
- Node.js 22
- Rust stable toolchain и компоненты, необходимые для сборки Tauri

### Установка зависимостей

```powershell
npm install --legacy-peer-deps
```

### Запуск в режиме разработки

```powershell
npm run desktop:dev
```

### Проверка типов и production-сборка интерфейса

```powershell
npm run lint
npm run build
```

### Сборка установщика Windows

```powershell
npm run desktop:build
```

Готовый установщик NSIS обычно находится в `src-tauri/target/release/bundle/nsis/`.

## Публикация релиза

Workflow **Build Windows App (.exe)** запускается вручную через вкладку **Actions**. Он проверяет TypeScript, собирает приложение и публикует установщик Windows в [GitHub Releases](https://github.com/Vercelsh/PERSONA/releases). Номер релиза берётся из поля `version` файла `src-tauri/tauri.conf.json`. Перед выпуском следующей версии синхронно обновите версию в `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml` и `package.json`, отправьте изменения в `main` и запустите workflow.
